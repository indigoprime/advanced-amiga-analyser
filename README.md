# Advanced Amiga Analyser manual

A 2026 Wyoretro reproduction of the original Wilcom Australia manual. Current edition: **v0.9**, 13 October 2026.

## Download

- [Read the manual (PDF)](Advanced_Amiga_Analyser_Manual_v0.9.pdf)
